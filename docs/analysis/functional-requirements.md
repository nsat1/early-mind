# Функциональные требования: релиз 1

Связанные документы: [сценарии использования (UC)](use-cases.md), [бизнес-правила (BR)](business-rules.md).

## Навигация

| ID | Требование | Приоритет | Связь |
|---|---|---|---|
| FR-37 | Система должна показывать в разделе «Алфавит» вкладки «Буквы» и «Задания» и кнопку возврата на главную страницу, а при входе в раздел открывать вкладку «Буквы» | Must | UC-01, UC-04 |
| FR-38 | Система должна при запуске показывать главную страницу с разделом «Алфавит» и кнопкой «Для родителя» | Must | UC-01, UC-05 |
| FR-39 | Система должна по стрелке «←» в карточке буквы возвращать к списку букв с тем же фильтром | Must | UC-02 |

## Список букв и фильтр

| ID | Требование | Приоритет | Связь |
|---|---|---|---|
| FR-01 | Система должна показывать список из 33 букв с картинками в порядке алфавита | Must | UC-01, BR-09 |
| FR-02 | Система должна фильтровать список по виду букв: гласные, согласные, знаки или все | Must | UC-01, BR-09 |
| FR-03 | Система должна обозначать фильтры иконками, понятными без умения читать | Must | UC-01 |
| FR-04 | Система должна визуально отличать изученные буквы от неизученных | Must | UC-01, BR-01 |
| FR-05 | Система должна открывать карточку буквы по нажатию на её картинку в списке | Must | UC-01 |

## Карточка буквы

| ID | Требование | Приоритет | Связь |
|---|---|---|---|
| FR-06 | Система должна показывать ту же картинку буквы, что в списке: заглавная и строчная буква в печатной форме, без искажения | Must | UC-02 |
| FR-07 | Система должна при открытии карточки воспроизводить звук буквы, а не её название | Must | UC-02 |
| FR-08 | Система должна повторно воспроизводить звук буквы по нажатию на её картинку или кнопку озвучивания | Must | UC-02 |
| FR-09 | Система должна показывать слова-примеры буквы с иллюстрациями | Must | UC-02, BR-10 |
| FR-10 | Система должна озвучивать слово по нажатию на его иллюстрацию или кнопку озвучивания | Must | UC-02 |
| FR-11 | Система должна для Ъ и Ь вместо звука воспроизводить название знака: «твёрдый знак», «мягкий знак» | Must | UC-02, BR-07 |
| FR-12 | Система должна отмечать букву изученной при первом открытии её карточки | Must | UC-02, BR-01 |

## Обучение по порядку

| ID | Требование | Приоритет | Связь |
|---|---|---|---|
| FR-13 | Система должна по кнопке «Начать обучение» открывать карточку первой по алфавиту неизученной буквы с учётом фильтра | Must | UC-03 |
| FR-14 | Система должна по кнопке «Дальше» открывать карточку следующей по алфавиту буквы с учётом фильтра | Must | UC-02, UC-03 |
| FR-15 | Система должна после последней буквы с учётом фильтра или если все такие буквы изучены показывать экран завершения с предложением пройти проверочные задания | Must | UC-02, UC-03 |

## Проверочные задания

| ID | Требование | Приоритет | Связь |
|---|---|---|---|
| FR-16 | Система должна формировать задания только по изученным буквам с учётом ограничений для Ъ, Ь и Ы | Must | UC-04, BR-01, BR-07 |
| FR-17 | Система должна показывать три варианта ответа в случайном порядке, один из которых верный | Must | UC-04 |
| FR-18 | Система должна в задании по звуку воспроизводить звук буквы и повторять его по нажатию на кнопку звука, а верным ответом считать эту букву | Must | UC-04 |
| FR-19 | Система должна в задании по картинке показывать иллюстрацию слова-примера, озвучивать слово и повторять его по нажатию на иллюстрацию, а верным ответом считать букву, с которой оно начинается | Must | UC-04 |
| FR-20 | Система должна при верном ответе показывать анимацию одобрения и переходить к следующему заданию | Must | UC-04 |
| FR-21 | Система должна при неверном ответе подсвечивать верный вариант и воспроизводить его звук | Must | UC-04 |
| FR-22 | Система должна при отсутствии изученных букв для заданий предлагать сначала изучить буквы | Must | UC-04 |

## Прогресс, статистика и сессии

| ID | Требование | Приоритет | Связь |
|---|---|---|---|
| FR-23 | Система должна хранить изученные буквы, статистику букв и историю сессий на устройстве и сохранять их после перезагрузки страницы и перезапуска браузера | Must | UC-02, UC-04, UC-05 |
| FR-24 | Система должна обновлять статистику буквы при открытии её карточки и при каждом ответе | Must | BR-02, BR-05 |
| FR-25 | Система должна учитывать сессии и их длительность | Could | BR-08 |
