# Аналитика: релиз 1

## Принципы

- События обезличены: в них нет идентификаторов устройства и пользователя, cookie и IP-адреса.
- Прогресс конкретного ребёнка остаётся на устройстве (FR-23, BR-06). На сервер попадают только факты, которые имеют смысл в сумме по всем устройствам.
- Отправка событий не мешает обучению: она идёт в фоне, ошибки отправки ребёнку и родителю не показываются.
- Аналитика не собирает персональные данные (NFR-18).

## Метрики

| Метрика | Определение | Формула | Источник |
|---|---|---|---|
| Сильные буквы | Буква сильная по правилу BR-03. Для родителя считается на устройстве | Медиана `strong_letters` по сессиям за неделю | `session_finished` |
| Точность по букве | Доля верных ответов по букве на всех устройствах. Показывает сложные буквы и проблемы контента | Число `answer_given` с `correct = true` / число всех `answer_given` по букве за период | `answer_given` |
| Завершённые сессии в неделю | Завершённая сессия — сессия, в которой был хотя бы один ответ в проверочном задании: ребёнок не только посмотрел карточки, но и закрепил их | Число `session_finished` с `answers > 0` за неделю | `session_finished` |
| Длительность сессии | Длительность по правилу BR-08, без времени бездействия | Медиана `duration_seconds` и доля сессий длительностью от 5 до 10 минут за неделю | `session_finished` |
| Возврат через 7 дней | Доля устройств когорты, открывших приложение через 7–13 дней после первого визита. Когорта — устройства с первым визитом в одну неделю | Число `app_opened` с `days_since_first_visit = 7-13` / число `app_opened` с `days_since_first_visit = 0` для одного значения `first_visit_week` | `app_opened` |

Возврат считается без идентификатора устройства: каждое устройство отправляет `app_opened` один раз на диапазон, поэтому число событий диапазона равно числу устройств когорты, дошедших до него.

## Конверт события

| Поле | Тип | Описание |
|---|---|---|
| `name` | Строка | Имя события из каталога |
| `schema_version` | Целое | Версия схемы полей события, начиная с 1 |
| `app_version` | Строка | Версия веб-приложения, например `1.0.0` |
| `properties` | Объект | Поля события |

Время получения события фиксирует сервер с точностью до часа. Время устройства не передаётся.

## Каталог событий

### app_opened

**Когда:** при открытии приложения, если устройство впервые попало в новый диапазон дней с первого визита. Дата первого визита и отправленные диапазоны хранятся на устройстве.

| Поле | Тип | Значения | Описание |
|---|---|---|---|
| `days_since_first_visit` | Строка | `0`, `1`, `2-6`, `7-13`, `14-29`, `30+` | Диапазон дней с первого визита |
| `first_visit_week` | Строка | Неделя по ISO 8601, например `2026-W42` | Неделя первого визита — когорта |

### session_finished

**Когда:** при завершении сессии по правилу BR-08 — через 5 минут без действий или при закрытии приложения.

| Поле | Тип | Значения | Описание |
|---|---|---|---|
| `duration_seconds` | Целое | 0–7200, кратно 10 | Длительность сессии без бездействия, округлена до 10 секунд |
| `cards_opened` | Целое | 0 и больше | Число открытий карточек букв |
| `answers` | Целое | 0 и больше | Число ответов по правилу BR-02 |
| `correct_answers` | Целое | От 0 до `answers` | Число верных ответов |
| `learned_letters` | Целое | 0–33 | Число изученных букв на устройстве по правилу BR-01 |
| `strong_letters` | Целое | 0–33, не больше `learned_letters` | Число сильных букв на устройстве по правилу BR-03 |

### answer_given

**Когда:** при ответе в проверочном задании — первом выборе ребёнка по правилу BR-02.

| Поле | Тип | Значения | Описание |
|---|---|---|---|
| `alphabet_id` | Строка | Код языка по ISO 639-1, например `ru` | Алфавит задания |
| `letter_code` | Строка | Код буквы, например `zh` | Буква, которую нужно было найти |
| `task_type` | Строка | `sound`, `picture` | Тип задания: по звуку (FR-18) или по картинке (FR-19) |
| `correct` | Логическое | `true`, `false` | Верный ли ответ |

## Доставка и хранение

- Веб-приложение копит события и отправляет их пачкой до 50 штук в `POST /api/v1/analytics/events` при завершении сессии и при скрытии страницы. Для отправки при закрытии страницы используется `navigator.sendBeacon`.
- Доставка — не более одного раза: при ошибке события отбрасываются и не отправляются повторно. Потеря части событий допустима, а повтор без идентификатора события привёл бы к двойному счёту.
- Несовместимое изменение полей события получает новую `schema_version`. Сервер принимает текущую и предыдущую версии.
- IP-адреса не сохраняются ни в БД, ни в журналах веб-сервера для эндпоинта событий.
- События хранятся 12 месяцев, затем удаляются.
